# CRM fonts

These unmodified font files come from the Google Fonts repository and are served by `next/font/local`. Builds never fetch Google font stylesheets or font files.

| File | Source | Usage |
| --- | --- | --- |
| `PlusJakartaSans-Variable.ttf` | https://github.com/google/fonts/blob/main/ofl/plusjakartasans/PlusJakartaSans%5Bwght%5D.ttf | Normal variable font, weights 300–700 used by CRM |
| `BebasNeue-Regular.ttf` | https://github.com/google/fonts/blob/main/ofl/bebasneue/BebasNeue-Regular.ttf | Display font, weight 400 |

The full font files preserve the supported character sets. The original SIL Open Font License texts accompany each family in this directory. Keep them with the fonts when distributing the app.

Font variables belong on the root HTML element so the global font stacks and their fallbacks resolve consistently. The navigation brand uses the same Bebas Neue variable.
